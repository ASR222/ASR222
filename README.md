### What I've built

**[CortexAI](https://github.com/ASR222/cortex-ai)** · [live](https://cortex-gateway-720170616128.asia-south1.run.app/)<br/>
One chat box that routes each message to the right specialist agent: chat, cited web search, coding with a live preview, PDF and image questions, or a generated report, deck or image. Go services for the gateway, auth, chat and billing; a Python LangGraph service for the agents. Runs on Cloud Run, built with Terraform.

**[HazeBusters](https://github.com/ASR222/hazebusters)** · [live](https://main.dxwuap9t49si3.amplifyapp.com)<br/>
Air quality for places with no monitor nearby: a CPCB-style AQI with its source and confidence, a go or stay-in call for schools and outdoor workers, and advice in English and Hindi, read aloud. Serverless on AWS with Lambda, Bedrock and Polly. Built with a team at WeMakeDevs × AWS Environmental Hacks 2026.

**[NovaCRM data warehouse](https://github.com/ASR222/B2B-SaaS-Data-Warehouse-Analytics-SQL-Server)**<br/>
SQL Server warehouse that joins a SaaS company's ERP and CRM data through bronze, silver and gold layers into a star schema for MRR, churn and customer health.

**[Warehouse KPI dashboard](https://github.com/ASR222/Warehouse-KPI-Process-Optimization-Dashboard)**<br/>
Streamlit dashboard for fulfilment operations, with ±2σ KPI alerts, a process Sankey, a Lean what-if simulator and root-cause analysis.

**[Resume Analyzer](https://github.com/ASR222/Resume-Analyzer)**<br/>
REST API that parses PDF resumes and scores them for an ATS, with OTP sign-up, JWT auth and a local Phi-3 model on Ollama.
